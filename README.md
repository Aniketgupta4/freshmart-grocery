# FreshMart Web Platform 🛒✨

FreshMart is an ultra-fast quick-commerce grocery web platform delivering farm-fresh produce, dairy, bakery, and daily essentials with high-speed 10-minute dispatch.

## Features
- **Modern Clean Light UI**: Crisp design tailored with Tailwind CSS and Lucide icons.
- **Dynamic Catalog**: Full integration with the live FreshMart backend on Render.
- **Interactive Product Details**: High-resolution image showcase, 1-click in-card stepper, and quantity controls.
- **Smart Cart & Checkout**: Real-time delivery calculations, coupons, and seamless ordering.
- **Executive Admin Suite**: Full product, category, coupon, order dispatch, and customer support management.
- **Android App Download**: Direct 1-click download of the `FreshMart-FinalApp.apk` with live version tracking.

## Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## Backend API
Connected to: `https://freshmart-backend-nrt4.onrender.com/api/`
